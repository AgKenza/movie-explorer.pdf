Sensa - Explorez, découvrez, regardez

À propos du projet

Sensa est une plateforme moderne conçue pour explorer, découvrir et consulter facilement un catalogue de films soigneusement sélectionnés.

🎯 Objectif

Offrir une interface fluide, intuitive et responsive pour naviguer à travers des informations cinématographiques de qualité.

🛠️ Technologies utilisées

  • HTML5 / CSS3 (Grid, Flexbox)
  • JavaScript (Async/Await, Fetch API)
  • Git & GitHub (Version control & Pull Requests)
